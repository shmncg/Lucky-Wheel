# Classroom Lucky Wheel 🎯✨

An interactive, responsive classroom lucky wheel application designed for roll calls, student groupings, team draws, and classroom rewards. Built with modern web standards, featuring a **Cosmic Blue Starfield & Nebula** aesthetic with **Pavé Diamond Glitter** and animated 4-point star lens flares.

## 🌟 Features

- **Dual Interactive Draw Modes**:
  - 👥 **Teams Mode**: Default 6 Paleozoic periods (`Cambrian`, `Ordovician`, `Silurian`, `Devonian`, `Carboniferous`, `Permian`) with dynamic stepper counter `[-] [count] [+] [Set]`.
  - 🔢 **Seat Numbers Mode**: Pure roll call numbers (`1~N`) without prefixes, perfect for student callouts.
- **Cosmic Blue Starfield Aesthetic**:
  - Deep midnight navy nebula background with starlight particles and glowing cosmic clouds.
  - Double-ring platinum & diamond-paved glitter border with 320 crystalline sparkles.
  - 12 animated 4-point lens flare star glints (✨) with smooth breathing twinkle loop.
  - Faceted sapphire crystal dagger pointer and glowing center spin button.
- **Audio & Visual Effects**:
  - Built-in Web Audio API synthesizer for realistic ticking sounds and victory fanfares (zero external audio files needed).
  - Celebration confetti explosion upon winner announcement.
  - Draw history tracking log with timestamps and rank orders.
- **Classroom Ready**:
  - Fullscreen / Projector mode toggle.
  - Responsive design optimized for smartboards, desktops, tablets, and phones.
  - Duplicate winner exclusion option ("Remove from Wheel").

## 🚀 Live Demo

You can host this project on **GitHub Pages** by following the setup steps below.

### GitHub Pages Setup Instructions

1. Push this repository to GitHub:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<YOUR-USERNAME>/<REPO-NAME>.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages** (under the "Code and automation" section).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
3. Within 1-2 minutes, your website will be live at:
   `https://<YOUR-USERNAME>.github.io/<REPO-NAME>/`
